# Lokale Unterrichtsmaterialien

Der Unterordner `BPE1` wird mit `scripts/sync-materials.ps1` aus dem bereits
vorhandenen Materialordner `../BPE1` erzeugt.

Enthalten sind nur Lernendenmaterialien:

- Aufgabenstellungen
- Excel-Tabellenvorlagen
- Informationsmaterialien
- Lernvideos
- Aktivitätsverfolgungen

Musterlösungen und Lehrer-Kompetenzraster werden nicht in den öffentlich
erreichbaren Webordner kopiert. Der erzeugte Ordner `BPE1` ist von Git
ausgeschlossen, bis die Nutzungsrechte für eine öffentliche Weitergabe der
einzelnen Dateien geklärt sind.
