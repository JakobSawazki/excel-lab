# Excel-Lab – offene Punkte und Fragen an Jakob

So funktioniert die Datei: Claude (und Codex) schreiben offene Fragen mit
Nummer hierher. Jakob antwortet direkt darunter mit derselben Nummer, zum
Beispiel `Antwort 3: …`. Claude liest die Datei bei jeder Arbeitsrunde,
setzt beantwortete Punkte um, löscht sie danach hier und dokumentiert sie in
`documentation.md` (Taskstatus) und `claude2codex.md`.

Nummern werden nicht neu vergeben, auch wenn ein Punkt gelöscht ist.
